# Assets Directory

Place your mobile app assets here:

- `icon.png` - App icon (1024x1024)
- `splash.png` - Splash screen
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon
- `/images/` - Other images
- `/fonts/` - Custom fonts

These assets are referenced in app.json configuration.
