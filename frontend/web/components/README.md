# Components Directory

This directory contains reusable React components for the Bills.ai web application.

## Structure

- `/auth` - Authentication related components (LoginForm, RegisterForm)
- `/bill` - Bill management components (BillCard, BillUpload, SplitMethods)
- `/session` - Session management components
- `/ui` - Base UI components (Button, Input, Modal, etc.)
- `/layout` - Layout components (Header, Footer, Navigation)

## Guidelines

- Each component should be in its own file
- Use TypeScript for type safety
- Export components as named exports
- Include PropTypes or TypeScript interfaces
- Keep components small and focused on a single responsibility
